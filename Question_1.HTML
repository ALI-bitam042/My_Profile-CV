Java Program displaying Hello Mmanga

Public class Mmanga {
    Public static void main(String[] args) {
        System.out.println(“Hello, Mmanga!”);
    }
}

Explanation:

This is a basic Java program that prints ”Hello, Mmanga!” to the console.

  • public class Mmanga: Defines a public class named HelloMmanga.
  • public static void main(String[] args): The main method where the program starts.
  • System.out.println(…): Prints the given string to the console.
